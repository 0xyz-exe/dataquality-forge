# Contributing to DataQuality Forge

Thank you for contributing!

## Guidelines
1. Fork the repository and create a feature branch (`git checkout -b feature/awesome-check`).
2. Run automated test suite:
   ```bash
   pytest -v
   ```
3. Ensure no linting regressions:
   ```bash
   ruff check .
   ```
4. Open a clear Pull Request with reproducible verification steps.
